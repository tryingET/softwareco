# Autonomous CTO canary — problem and intent

## Problem

Decision 77 proved that fresh Pi workers can reconstruct portfolio state and drive a federally governed owner outcome inside finite human-authorized epochs. It intentionally forbids a scheduler and appoints no CTO between epochs. The tracked `softwareco-cto` mode is therefore an explicit operator workbench, not an always-running service.

Softwareco now needs to test a different question: can an always-available CTO-shaped observer continuously sense the registered `softwareco/owned` portfolio, detect drift and blockers, rank evidence-backed theses, and prepare D2E-ready drafts without acquiring owner or runtime authority?

## Intended test

Run one supervised 24-hour canary with:

- one fresh `pi --mode rpc --no-session` process per hourly cycle;
- a `replace_base` CTO prompt that replaces Pi's static native base while retaining the dynamic host envelope;
- complete AK-registered owned-portfolio sensing;
- proposal-only observations, ranked theses, uncertainty, and human-ready drafts;
- recommendations for ordinary tasks, deep review, visible loops, Nexus-like coordination, or transcendent iteration without self-dispatch;
- exact direct-human acceptance and activation gates;
- no owner-repo, AK, FCOS, publication, release, or external-system mutation by the canary.

## Non-goals

The canary does not create a permanent office, autonomous task executor, scheduler-backed backlog, owner proxy, release agent, or canonical portfolio state store. Model API calls and bounded local canary traces are the only intended operational effects. Any broader autonomous authority requires evidence from this canary and a later decision.

## Success

Success is verified 24-hour supervision, fresh-cycle isolation, exact prompt composition, truthful portfolio coverage reporting, useful evidence-linked proposals, bounded cost/runtime, automatic expiry, and zero canary-authored authority or owner lifecycle mutation. A useful result may still recommend stopping rather than expanding autonomy.
