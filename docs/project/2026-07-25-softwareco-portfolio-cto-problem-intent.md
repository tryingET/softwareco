# Problem and intent — Softwareco owned-portfolio CTO

## Problem

Decision 68 proved bounded CTO/template safety but did not create an operable portfolio CTO. Its delegation expired at the issue-tracker canary terminal decision. Softwareco now has:

- an expired CTO charter projection;
- an active portfolio of independently owned repositories under `softwareco/owned`;
- AK-native direction, task, decision, and evidence authority;
- Pi Modes as a prompt-policy mechanism;
- no tracked CTO mode, preset, or `/cto` entrypoint;
- no current authority for an agent to select technical investments across the owned portfolio.

Calling an ordinary Pi session “the CTO” would therefore be role-play. Generating an agent repository would package behavior but still would not appoint the role. Leaving portfolio selection entirely implicit would preserve local autonomy at the cost of company-level technical coherence.

## Operator intent

The accountable human selected an ambitious first mandate:

- jurisdiction: the registered `softwareco/owned` portfolio, at least initially;
- authority: autonomous technical portfolio sequencing within accepted product postures;
- WIP: at most two active portfolio waves and six active owner-repo execution tasks;
- coordination: native FCOS Layer 5 only for genuine cross-repo work;
- proof: an evidence-backed portfolio thesis plus one completed outcome wave;
- duration: earliest of 30 days, the mandate canary terminal decision, revocation, or supersession;
- entrypoint: a tracked Pi mode plus `/cto <objective>` prompt template.

## Intended outcome

Create a human-accountable constitutional CTO workbench that:

1. reads AI Society principles, Softwareco direction, and owner-repo product posture/evidence;
2. ranks technical investments across `softwareco/owned`;
3. selects and operates bounded portfolio waves without absorbing owner authority;
4. executes only through exact AK tasks in source-owner repositories;
5. uses FCOS only when coordination is genuinely cross-repo;
6. measures outcome evidence rather than counting activity;
7. reaches a human terminal review within the finite mandate;
8. remains advisory whenever delegation is missing, expired, revoked, ambiguous, or outside jurisdiction.

## Why this is Tier 1

The change expands CTO jurisdiction from one template/canary domain to portfolio-level technical sequencing, changes decision rights, and introduces a durable company operator contract. It therefore requires the full problem/evidence/RFC/review/ADR/planning membrane before delegation or implementation activation.
