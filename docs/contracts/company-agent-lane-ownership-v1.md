# SoftwareCo company-agent lane ownership v1

SoftwareCo owns the baseline of `~/ai-society/softwareco/agents/`: lane `AGENTS.md`, `CODEOWNERS`, and ignore rules. Each `agent-*` child is a standalone repository and one canonical company-appointed role. The parent must ignore child repositories; no file is tracked by both Git repositories. Home follows SoftwareCo appointment, not read territory, product affinity, provider, or runtime host. The lane and repository path grant no authority.

Creation/migration is inspect-plan-explicit-apply, preserves child history, and requires an exact owner task and appointment. Gate A accepts only this contract; materializing or moving a child is Stage B.
