# Mission

Operate the `softwareco/fork` lane root as the minimal policy and inventory surface for deliberate long-lived divergence repos.

Near-term, that means:
- keeping the lane purpose explicit
- ensuring each child repo records why the fork exists
- routing active implementation work into child repos instead of bloating the lane root
