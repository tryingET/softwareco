# Vision

A new operator can enter `softwareco/owned`, understand the lane boundary, locate the correct child repo, run deterministic preflight checks, inspect engineering-core adoption coverage, and choose the next lane-root action within a single session.

The lane root should expose generated adoption visibility without owning shared scanner doctrine: `core/engineering-core` owns reusable scanner semantics, while `softwareco/owned` owns its dashboard, JSON snapshot, and adoption follow-up waves.
